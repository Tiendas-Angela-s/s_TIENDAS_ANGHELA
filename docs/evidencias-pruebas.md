# Matriz de casos de prueba y evidencias — CU-011

## 1. Objetivo

Definir los escenarios de prueba para el caso de uso CU-011: Registrar y confirmar transferencia entre puestos, verificando las reglas del negocio, los flujos alternativos y las restricciones correspondientes.

Los casos de prueba permitirán comparar los resultados esperados con los resultados obtenidos durante la ejecución del sistema.
